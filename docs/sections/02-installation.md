## Installation

Install the package with Composer. There is nothing to register or configure.

### Requirements

- PHP 8.5 (`>=8.5 <8.6`)
- No runtime dependencies

### Composer Installation

```bash title="Terminal" no-line-numbers
composer require pharaonic/php-smart-enum
```

Composer autoloads the `Pharaonic\SmartEnum` namespace. The only class you use is the `Pharaonic\SmartEnum\SmartEnum` trait.

:::success Installation Complete
You're all set! Add `use SmartEnum;` to any of your enums.
:::
